# 企业数据仓库管理平台

面向企业数据团队的一站式数据仓库建设与管理平台。覆盖原始数据落地、多层清洗转换、维度建模、事实建模、分区治理、质量校验、血缘追踪与历史补数的完整数仓链路。

这是一个前后端分离的管理平台：前端 React + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/              统一请求封装
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/          每个业务模块一组接口
│   ├── app/services/         业务规则与状态流转
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 约定

- 每个模块的前端页面在 `frontend/src/views/<模块>/index.vue`，后端接口在
  `backend/app/routers/<模块>.py`，业务规则在 `backend/app/services/<模块>.py`。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。

## 汇总层聚合重算与版本口径

聚合重算的共享状态集中在 `backend/app/services/versioning.py`，串起
「事实定义 → 汇总层聚合流水 → 应用层输出」的取数链路：

- **受影响窗口判断**：先按事实定义的分区字段（粒度）、度量字段、分区字段判断哪些汇总窗口
  已经产出结果；再用聚合流水的汇总粒度与时间窗口界定本次聚合范围（如按月窗口按天展开）。
  事实粒度比汇总粒度更粗时，一个事实分区会映射到多个汇总窗口。
- **只重算待处理分区**：批次只包含当前口径版本下尚未生效的分区；已生效分区记为「已跳过」。
- **幂等提交**：批次以「汇总表 + 汇总粒度 + 时间窗口 + 口径版本」为幂等键，同一窗口重复提交
  复用在途批次，不重复登记分区。
- **版本切换**：新重算结果先记为「待核对」，旧结果继续作为当前可消费版本（保留为「上一版本」）；
  一致性核对（覆盖分区 / 行数偏差 / 口径是否仍为当前生效版本 / 是否有待复核迟到数据）通过后，
  新版本才切为「已生效」。
- **迟到数据**：数据更新时间晚于聚合批次的结果进入「待复核」，不静默覆盖；早于批次的按该分区
  「当时已生效」的度量口径补算，补算批次同样需要核对。补算出的旧口径版本若晚于当前消费版本，
  核对时并入当前可消费版本，不回退已消费口径。
- **应用层同步**：应用层输出页展示汇总层当前可消费版本、窗口与消费状态，并同步待复核分区；
  待复核期间标记「待复核，暂不消费」，不继续引用旧窗口的已切版结果。

相关接口：

| 接口 | 说明 |
| --- | --- |
| `GET /api/dws/{id}/recalc-plan` | 受影响窗口、事实口径版本、待处理/已生效分区与判断依据 |
| `POST /api/dws/{id}/recalculate` | 提交重算（幂等） |
| `POST /api/dws/{id}/batches/{batch_id}/verify` | 一致性核对并切换可消费版本 |
| `POST /api/dws/{id}/late-partitions` | 迟到分区补入（按更新时间决定待复核或补算） |
| `POST /api/dws/{id}/reviews/resolve` | 复核迟到数据并释放待复核状态 |
| `GET /api/dws/{id}/batches` | 重算批次与分区版本账本 |
| `POST /api/factdef/{id}/metrics` | 修改已发布事实的度量口径，登记新口径版本并同步下游受影响窗口 |
| `GET /api/factdef/{id}/versions` | 口径版本历史与下游聚合流水状态 |
| `GET /api/ads/{id}/consumable` | 应用层当前可消费的聚合版本、窗口与待复核状态 |
